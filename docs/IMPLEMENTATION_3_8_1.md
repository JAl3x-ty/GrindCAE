## 开发边界

### 已编写的实现

新增 `src/grindcae/literature_history/`，通过组合输入调用既有力模型、网格和J2历史接口。
GUI新增第八种分析“文献力驱动·弹塑性单程”，原独立文献力模式继续保留。

1. **重算力来源。** 联算从工程读取轮径、切深、速度、宽度和屈服强度。
   论文力每次运行重新计算，旧经验比能/力比只在内部用作总力的代数传递，不作为预测参数。
   工艺变化进入新指纹；输入不依赖此前导出的固定工况力。
2. **分项空间载荷。** 塑性流动、断裂应力、前刀面摩擦、磨损面摩擦分别累加到周向条带。
   磨损力均分给动态有效磨粒，条带内常值载荷与现有P1边函数精确积分。
   分项与总力保留守恒拒绝条件，宽度不重复相乘。
3. **共享历史求解。** 同一网格分别计算均匀和条带载荷两条路线，调用既有
   `advance_prepared_history`，各自独立提交材料状态，沿用Newton、子步、失败回滚和最终卸载。
4. **软件链路。** 注册分析设置、后台分派、进度、结果读取、分类图片/数据、Origin导出。
   输入与材料来源随工程保存；新结果采用独占目录发布、相对路径、文件哈希和组合回读。
5. **结果布局。** 实际生成论文力/磨粒、条带模板、分量投影CSV、两路线历史/VTU/节点/单元、
   最终残余场图、表面位移图及对比图。原生历史子目录保留，根目录提供明确命名的展示副本。

### 模型假设

- 周向条带是新增的宏观空间闭合；论文未给出这套完整压力分布。
- u=0为运动坐标接触区前端，浅切接触长度中的磨粒坐标映射到现有精确圆弧投影长度。
- 进入/退出保持原接触比总力缩放，截取形状独立归一；某分量截取区无支撑时，
  仅该分量按相同目标力均匀分配并记录fallback。
- 砂轮粒径/组织号/角度/修整高度使用文献参数页，未自动替换为工程砂轮牌号。
- E、ν、Et与屈服强度来自工程材料；β、断裂应力、摩擦来自文献页，其他材料属于未标定迁移。
- 继承3.8.0的入口、独立轴向轨道、K1与β外推限制；本轮没有通过调参消除这些科学缺口。

### 入口

使用候选版时，入口为根目录 `Start-GrindCAE-3.8.1.cmd`，
在分析页选择“文献力驱动·弹塑性单程”，使用工程几何/网格/材料/工艺及文献参数页。
该模式需要完整工程输入；旧纯力示例没有FE工程输入，不能直接当作完整联算案例。
原3.8.0启动器仍指向此目录当前源码；要恢复rc2应从归档恢复到独立目录，不能仅靠旧文件名区分版本。
