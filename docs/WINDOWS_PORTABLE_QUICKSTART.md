# GrindCAE 3.8.1 Windows 便携版

## 启动

将ZIP完整解压到可读目录，双击 `GrindCAE.exe`。保留同目录的 `_internal`，无需另装Python。
既有 `.gcae` 工程可从“打开工程”载入。保存工程和结果时选择自己的工作目录。
运行 `GrindCAE-Diagnostics.exe` 可检查运行库；命令行加 `--literature-smoke --output-dir <新的目录>` 可执行小规模文献/J2联算及Tk工程回读。

## 能力

文献力模式计算塑性流动、材料去除、前刀面摩擦及磨损面摩擦分量。
“文献力驱动·弹塑性单程”将这些力映射到条带载荷，复用J2历史内核，对比均匀/条带的应力、位移、塑性累积和卸载残余。
工艺和材料需完整配置。联算输出必须选择新目录。参考小工况可能保持弹性，塑性应变为0属于正常结果。
高级参数长标签自动换行；鼠标置于当前节点普通控件上可滚轮上下滚动。

## 边界

砂轮重建和条带压力分布含明确的补齐假设。材料迁移未标定，独立实验验证未完成。
论文联算不提供真实切屑分离、热耦合或粗糙度预测。旧真实接触入口是保留功能，其4.0更新不属于本次验收。
开发机冻结程序检查不替代独立电脑验收。第三方许可证见 `LICENSES` 和 `THIRD_PARTY_NOTICES.txt`。
