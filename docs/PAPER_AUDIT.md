## 开发边界

该文提出含实验标定项的解析/统计磨削力模型。研究对象为440C不锈钢与WA80H12V白刚玉砂轮，
比较干磨、浇注、MQL与NMQL。它给出单磨粒接触面应力假设和积分力，再按随机砂轮动态有效磨粒求和。
本轮实现其公开公式和显式记录的离散重建假设，提供两种公式约定，不把作者实验误差当作本软件性能。
真实接触、有限变形、裂纹/切屑、弹塑性场、表面形貌及独立实验预测不在本内核输出中。

### 公式合同与闭式表达

令a为SI切深，t=tanθ，A=acos(sqrt(β))，B=π/2−A，
`J=sin(A)+(cos(A)−1)/A`。式(2)原样使用6项Gaussian和Gompertz，分界3.8μm。
切削时 `r=π*t*δb/[2*(1−sin A)]` 为式(7)的δ02。

耕犁式(15)–(19)：

```text
Ft_material = δs*a²*t
Fn_material = (π/2)*δs*a²*t²
Ft_rake     = (π/2)*μ*δs*a²*t²
Fn_rake     = (π/2)*μ*δs*a²*t
```

切削两约定统一表达，令q=2（printed）或1（continuous_projection）：

```text
δ1(α) = (δs+q*r)*α/A
δ0    = δs+r
Ft_material = a²*t * [(δs+q*r)*J + (δs+r)*(1−sin A)]
Fn_material = a²*t²* [(δs+q*r)*A/2 + (δs+r)*B]
F_rake = μ*a²*t/cosθ * [(δs+q*r)*A/2 + (δs+r)*B]
Fn_rake = F_rake*cosθ
Ft_rake = F_rake          [printed: Eq21最右端]
Ft_rake = F_rake*sinθ     [continuous_projection: Eq21中间定义]
```

程序将材料力按δs与δb分项为 `plastic_*` 与 `removal_*`，后者包含流动区的断裂应力依赖贡献。
这是一种透明代数分组，不逐项等同于论文仅碎屑区的 Ftc(02)/Fnc(02)，也不能解释为分离能量。
每颗磨粒力单位已经是N；不再乘砂轮宽度或FE厚度。β仅控制分区角度，并非再次相乘的体积分数。

磨损平面式(28)–(30)：`fn=4*K1*Nd*Vw/(Vs*D)`，`ft=μ*fn`。
SI下P0维度为Pa·m，Sw为m²，K1=P0·Sw为N·m。论文数值18.36未给单位，无法唯一转SI。

### 发现的排印冲突与缺失项

1. p.85文字把碎屑区与流动区角度范围反写；图4/6和2.2的积分采用碎屑[A,π/2]、流动[0,A]。
2. 式(9)与式(10)的断裂项差2倍，无法同时满足所述应力连续性。两个约定都保存，不暗改原式。
3. 式(19)法向左端误作Ftpf；式(21)中间的sinθ投影未进入最右端积分。两者经PDF图像确认，非提取误差。
4. 式(29)中δ与Sw不一致；按(23)/(24)/(30)的完整等式可明确识别。
5. 图8上方3.5μm与式2的3.8μm不同，正文还反置Gaussian/Gompertz颜色描述；优先式2和表2。
6. 式(39)在本附件中未见独立编号公式；文中矩阵生成引用(39)/(44)不能当完整伪代码。
7. Nx、Ny取整方式、粒径是否截断、式(40)振动上限/反射/重排/归一化、砂轮修整后的包络均未交代。
8. G(c)在式(42)未清楚定义；本重建解释为候选 protrusion G(z)，保留来源歧义。
9. 动态筛选的圆周周期入口、轴向交叉遮挡、首粒切深及边界没有完整算法。本版按独立轴向列和有限入口实现。
10. 文中“动态磨粒每单位面积约0.5”缺单位，未把它当作概率或强制保留一半。
11. 图16流程图为>2.84μm，而表3为2.85μm；使用表3。二者不影响同一切削力公式，仅阶段标签。
12. 图18润滑面板打印预测值与5.2节NMQL实测均值不同，两者必须区别；预测为图中65.01/28.21N，
    文本实测为65.06/28.48N。其余图中浇注65.08/29.50、MQL65.39/32.65、干磨65.53/39.99N。

### 式(40)重建为何尚未复现图15/18

按字面从零累计800个U[−Lr,Lr]随机增量，Lr≈78.77698μm，理论中心高度标准差为
`sqrt(800/3)*Lr≈1.286mm`，比粒径180μm大一个数量级。随后以全局最高磨粒为基准，
15μm切深会只接触极少数磨粒。固定种子2017实际结果另见 `outputs/paper_stochastic`。
这是可复现的字面重建反例，显示公开文字不足以确定作者程序的修整/约束规则。
不通过改变振动次数、截断高度、挑选种子或回调K1制造图18接近。

目前能够独立核验的是单磨粒力公式、明确磨粒排列的动态筛选及总力求和。
要关闭整轮精确复现门禁，需至少补齐作者砂轮生成/修整算法或G(z)/G(ag)、K1单位、
公式冲突处理和图18底层数值。可先用实测/指定逐磨粒切深调用已实现内核；该输入应明确来源。
