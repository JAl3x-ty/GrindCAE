### 总体数据流

```text
工艺 + 440C文献参数 + 粒度/组织号 + 修整高度假设 + 种子
 → 空间磨粒记录 → 静态接触 → 动态切深 → β与逐粒分项力
 → Fn/Ft、功率、种子散布与来源
    ├→ 本轮：工况绑定总力转换 → 旧force_model → 历史输入JSON
    └→ 下一段：逐粒空间载荷 → P1保守投影 → 共享历史求解器
       → 均匀/空间分布双路线 → 位移、应力、塑性应变、卸载残余与差分场
```

固定网格场计算保持宏观载荷响应含义。论文“塑性堆积”名称不自动赋予FE侧向堆积、
碎屑或材料分离输出。剖面粗糙度需要另外定义方向、采样、滤波与评价长度。

### 已落地的总力接口

legacy_bridge调用现有GrindingForceCase.from_dict与predict_grinding_force。
采用us=Ft*Vs/(Vw*ap*b)、Rnt=Fn/Ft，使旧接口原样传递当前工况的总力。
这些量只属于保存的单个工况，改变速度、切深、宽度或模型假设必须重新生成。
旧GUI允许编辑这些值；本轮适配器没有跨GUI强制锁定功能，来源清单明确说明这一限制。

历史输入同步轮径、切深、载荷、厚度=磨削宽度和文献屈服强度。
示例沿用旧演示E=210GPa、ν=0.3、Et=2GPa，标明未标定；δb=540MPa不能代替硬化斜率或损伤参数。
宽度已进入总力，投影不得再次乘宽度。FE厚度仍按原有定义进入刚度等量。
新输入与逐字段变化清单在outputs/legacy_point_bridge；旧文件没有覆盖。
实际运行：主内核3.0.1公共力API，Fn/Ft转换残差均0 N，历史输入经严格Schema解析。
没有运行FE或宣称场结果已完成。

### 后续完整工作段

1. **空间载荷与边界**：保留磨粒身份/坐标/四类力；定义周向坐标到接触区及工件力符号映射。
   复用旧投影的积分方法，新增四分量合同；旧三机制比例保持原义。
   比较有限入口、周期代表区及更长上游磨粒列；固定高度假设，不用K1吸收全部几何误差。
   记录磨损分配、载荷核宽度及网格敏感性，逐分量与总力均要求守恒。
2. **共享历史闭环**：复用prepare_elastoplastic_mesh_with_facet_tractions和advance_prepared_history。
   两路线使用相同网格、材料、位置、总力历史和Newton门槛；覆盖进入/满接触/退出/最终卸载。
   明确接触比缩放规则，避免裁剪磨粒后再次衰减；末端零载荷通过历史层处理。
   门槛包括力守恒、相同载荷下路线一致性、失败回滚与最终卸载。材料参数需独立来源。
3. **软件集成**：独立目录新增文献分析模式、输入指纹、新Schema/结果格式，复用结果浏览和保存能力。
   工况修改触发论文力重算；展示假设、参考点标定和未验证状态。
   自动验证、GUI人工验收及版本文档完成后再确定正式3.8.0发布范围。
