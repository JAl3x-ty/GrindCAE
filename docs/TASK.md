2. 单磨粒：式(3)–(22)，输出材料塑性流动、去除、前刀面摩擦各分量。
   1.18 μm 以下用耕犁；以上用切削公式，2.85 μm 只影响阶段标签。

4. 砂轮：式(31)–(44)，可提供明确逐磨粒切深直接核对力内核，或使用有记录假设的随机重建。
   种子、随机算法、取整、初始/边界规则全部持久化；不以调种子凑图18。
5. 合力：式(45)–(46)，逐磨粒求和；宽度通过磨粒数进入，不再乘宽度/厚度。

### 文献歧义处理（首算前登记）

- 原式(10)断裂应力项比式(9)连续性要求大一倍：提供 `printed` 与 `continuous_projection` 两种显式公式约定。
  `printed` 保留式(10)及式(21)最右端；`continuous_projection` 用 δ1=δ0·α/α1，Ftcf=Fcf·sinθ。
  修正来自文内连续性与投影关系，是本次重建的选择，不能冒称作者原程序实现。
- 式(19)左端重复 Ftpf，按法向投影识别为 Fnpf；式(29)中 δ 按式(23)–(24)/(30)识别为 Sw。
- θ 图9为圆锥半角；表6数值保留 1.047 rad，不再除以2。
- β 表2、图8文字/颜色、3.5与3.8边界有矛盾，遵式(2)+表2，不平滑连接、不强制 β(0)=0。
- Vg=38% 在式(35)中使用0.38；Nx、Ny 的整数规则论文缺失，重建固定 floor。
- 式(40)逐次均匀位移累加可产生远大于粒径的高度散布，论文未给约束/重排/归一化。
  原样随机游走实现须标注有限信息重建；不将任意限幅版本混作原文复现。
- 接触弧采用浅切近似 sqrt(D·ap)；每轴向列按圆周位置处理，有限入口首粒用静态切深、后续用上次有效磨粒。
  agmax 上限为当前静态切深，非正值为受遮挡；ag=0.5 agmax。这些离散边界规则为明确实现假设。
- K1=18.36 没有单位。示例可显式选择 N·mm 假设并换算为0.01836 N·m；报告该假设未获作者确认。
  不以此样例声称图18绝对力或4.19%/4.31%误差复现成功。
- 原始划痕、砂轮矩阵、随机种子和50次实测力未提供；材料参数仅属440C文献参数，不迁移为17CrNi2MoVNb标定。
