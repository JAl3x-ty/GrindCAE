## 开发边界

### 明确补齐的约定

- 新Schema 2和结果v2：修整平面z=0，均匀退缩量[0,H]，H默认90μm（平均半粒径）。
  均匀分布为给定支持下的最大熵选择；H本身为未实测几何假设，不是论文报告值。
- 粒径为表6区间内截断正态；平均粒径控制间距。局部力使用公共圆锥角和有效切深，
  抽样粒径记录不代表完整逐粒形貌作用。
- 有限入口为默认，周期接触代表区包络为敏感性选项，尚非完整砂轮周向轨迹。
- 推荐continuous_projection满足应力连续和摩擦投影，保留printed；β分段不变。
- K1明确为N·m，未标定默认0；固定种子2017–2032，仅对图18干磨预测Fn=65.53N反标。
  图中预测值为次级重建标靶，不是原始实验；没有声称已确定无单位数字18.36的含义。
- Schema 1数值代码未修改，新旧输入版本分派；已有结果不重写。

### 实际研究结果

命令：study_completed_model.py --output-dir outputs/completed_model_study。
生成3组新结果，发布流程按保存输入重算回读；study.png已查看。
扫描覆盖切深10–40μm、进给1–4m/min、轮速10–40m/s、宽20/50mm、退缩深度45/90/135μm。
扫描固定K1不反复标定；study.json保存全种子结果，parameter_sweeps.csv保存汇总。

| 结果 | 数值 | 含义 |
|---|---:|---|
| 未标定平均Fn | 42.649N | 关闭磨损，16种子 |
| 反标K1 | 5.28361N·m | 依赖当前几何/边界/公式 |
| 标定集合平均Fn | 65.530N | 标定约束，不能当验证误差0 |
| 未拟合干磨平均Ft | 43.992N | 图18为39.99N，相对差+10.006% |
| 新种子2033–2048平均Fn/Ft | 65.913/44.227N | 同一假设分布的抽样变化 |
| 浇注/MQL/NMQL法向差 | -3.821%/-2.631%/-4.531% | 与论文预测比较 |
| 浇注/MQL/NMQL切向差 | +19.403%/+17.724%/+19.264% | 未参与拟合 |
| 基准动态磨粒 | 194.875±10.788 | 均值±种子样本标准差 |
| 首颗入射磨粒非磨损Fn | 37.378N | 占非磨损法向约87.6% |
| 有效切深超过4.5μm | 平均68.5颗 | β超出划痕证据的外推 |

周期边界另行反标得到K1约19.8659N·m，与有限入口明显不同。
即使切向值更接近论文，也不能据此认定边界正确；一个法向点无法区分磨损与边界误差。
扫描中力随切深/进给增加而增大、随轮速增加而减小，均属于当前重建的数值行为。
