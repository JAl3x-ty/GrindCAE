### 启动与使用

1. 双击本目录根部 `Start-GrindCAE-3.8.0.cmd`。
2. 进入左侧“分析”，选择“文献磨削力·材料去除与塑性堆积”。
3. 点击“文献参数设置 / 同步工程工艺”，编辑并应用参数。
4. 选择新的输出目录，向下滚动至运行按钮并计算；到“结果”查看摘要、力分量图和磨粒 CSV。
5. 保存为 `.gcae` 工程；可用“完整归档”携带结果。

`outputs/integrated_acceptance_1790323597/literature.gcae`。
