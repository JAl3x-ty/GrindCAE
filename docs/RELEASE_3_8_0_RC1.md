# GrindCAE 3.8.0rc1 文献力模型桌面候选版

## 文档体系

2026-09-25，用户接受当前文献比较误差，优先要求软件化并授权核验。
TASK.md追加软件化范围；PROJECT_STATE.md登记候选版；本文件说明实际交付与接受边界。
INTEGRATED_KERNEL_UPGRADE.md保留总体设计，PAPER_AUDIT.md和RECONSTRUCTION_OUTCOME.md保留科学依据。
主工作区仍为应用3.0.1；独立包升级为3.8.0rc1，不修改真实接触内核。

## 开发边界

### 已实现

- 中文Tk桌面工作台，工程单位参数、15项数值输入、边界和公式选择、参考/未标定算例。
- JSON算例加载与另存；同名文件拒绝覆盖，保持输入原始精度和大整数随机种子。
- 单个后台计算线程，主线程处理界面事件；运行计时、防重复启动、错误恢复、运行期间关闭保护。
- 力与图表、前500颗磨粒浏览、完整CSV、假设与来源、历史结果打开。
- 输入变更后标记历史结果，禁止将失配结果作为当前参数的总力输入导出。
- 现有force_model输入导出；历史输入适配仍可通过独立PowerShell脚本执行。
- 小窗口参数滚动。双击Start-GrindCAE-3.8.0.cmd启动。

### 如何使用

1. 双击根目录Start-GrindCAE-3.8.0.cmd。
2. 默认“参考标定算例”，检查参数后点击“开始计算”。
3. 在“力与图表”“磨粒明细”“假设与来源”中查看结果；完整文件保存于outputs/desktop_runs。
4. 改参数后重新计算。点击“另存算例”保存为新JSON；“打开结果”选择含summary.json的目录。
5. “导出现有内核总力输入”选择目标父目录，软件自动建立新子目录；它只传递该工况的总力。
